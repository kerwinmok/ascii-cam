# ascii cam

turn your camera view into moving text

## start the app

open this folder in a terminal

run `python -m http.server 8000`

open `http://localhost:8000` in your browser

allow the browser to use your camera

## use the app

press start camera to begin

use the three line button to choose a camera

choose mono for black and white or color for color

press stop camera when you are done

the app uses a built in set of characters
