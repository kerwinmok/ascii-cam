# ascii cam

turn your camera into moving text

## run on windows

double click `run.bat`

allow the browser to use your camera

## controls

press `esc` or the three line button to open controls

start or stop the camera

choose a camera

switch between mono and color

choose a text resolution made for your camera

the small bar shows fps and camera and text size

choose a character set

make your own set with text or a json list

## run in a browser

open a terminal in this folder

run `python -m http.server 8000`

open `http://localhost:8000`

camera access needs localhost or a secure site
